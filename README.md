# 最后防线 · LAST LINE

Three.js 浏览器 3D 僵尸射击游戏。固定阵地、四类僵尸、两位独立首领、三把可升级武器，连续挑战五道防线。通过击杀赚取金币，在补给站购买升级和装备；每关约1–3分钟，清除定额敌人和首领后进入下一关。

## 本地运行

需要 Node.js 22.12+ 和支持 WebGL 2 的现代浏览器。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。首次点击“进入战斗”启用音效。

## 操作

| 操作                     | 效果                             |
| ------------------------ | -------------------------------- |
| 移动鼠标 / 手指拖动      | 瞄准                             |
| 按住左键 / 长按场地      | 持续开火                         |
| 1 / 2 / 3 或底部武器按钮 | 切换步枪、狙击、霰弹；释放开火   |
| R 或装填按钮             | 手动装填，空仓也会自动装填       |
| H 或血包按钮             | 消耗血包，回复50生命；满血不消耗 |
| G 或手雷按钮             | 消耗一枚手雷，投向准星位置       |
| F 或自动射击按钮         | 切换自动瞄准、射击与缺弹换枪     |
| 战前或结算时进入补给站   | 用金币升级武器、能力或购买装备   |
| Esc / P                  | 暂停或继续                       |
| 失败时 R / 重试本关      | 重新挑战当前关                   |
| 右上角声音按钮           | 静音或恢复声音                   |

步枪30发，狙击5发，霰弹6发；三枪各有有限备弹，需要轮换使用。步枪整匣装填；狙击与霰弹逐发装入，有一发就能中断装填开火，已装入的子弹不会丢失。切枪取消当前装填进度；暂停则冻结装填。

狙击以一发的伤害额度依次击穿前排，前排未死就无法继续穿透。霰弹近距扇面覆盖身体边缘，同时显示九束散射轨迹。每关有一轮集中尸潮；重装者更抗打、更难僵直，疾行者更容易被打停，潜行者可能闪避枪击。手雷不会被闪避，但对首领伤害较低。

自动射击默认关闭，可在战前或战斗中切换；开启后自动瞄准范围内敌人及首领存活弱点。当前枪弹匣与备弹耗尽会换到还有弹药的武器，霰弹射程外可切回长枪；所有枪打空便停止。手雷仍需手动使用。

第3关的重甲巨兽惧怕狙击；第5关的孵化主宰需要先瞄准发光瘤，逐个击破三个弱点，再攻击核心。首领发动攻击前有两秒预警。

每关补满生命、三把枪的弹匣和本关规定的备弹，失败重试当前关；五关完成后可以重新出击。金币与升级保留，已用的血包、手雷、复活甲和护甲不会因重试返还。失焦与切换浏览器标签自动暂停，返回后手动继续。

金币、升级与剩余道具自动保存在当前浏览器的本地存储中，刷新后从第一关出击。清除网站数据会清除资产；浏览器禁用存储时仍可游玩，补给站会提示资产不能保留。无账号、云存档或后端。

详细数值、五关配额、通关规则和计时边界见 [玩法文档](docs/gameplay.md)。首版以电脑验收，已提供响应布局、触摸按钮；手机性能仍需真机专项验证。

## 验证与构建

```sh
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:campaign
npm run test:soak
npm run preview
```

产物在 `dist/`，可由静态 HTTP 服务提供。GitHub Actions 在 PR 上执行单元测试、类型检查/构建和常规浏览器交互测试，不自动部署。

`test:campaign` 使用真实浏览器输入完成五关、验证最终胜利和重开；通过浏览器时钟缩短等待，不修改游戏状态。`test:soak` 执行五分钟实际墙钟运行并检查活体、尸体、特效和浏览器错误。这些软件渲染测试输出环境与FPS，不能作为硬件性能承诺。

## 实现

- `src/game/types.ts`：共享状态、四类敌人、三枪与五关数值。
- `src/game/simulation.ts`：不依赖渲染的战斗、装填、定额出怪与关卡状态机。
- `src/game/economy.ts`：金币购买、升级数值、道具库存和版本化本机存档。
- `src/game/world.ts`：程序化场景、角色/武器模型、动画与特效池。
- `src/game/audio.ts`：Web Audio 合成音效。
- `src/main.ts`：输入、页面生命周期、对局界面与主循环。

开发服务器显式使用 `/?inspect` 时提供只读 `window.__game.snapshot()` 和 `project()`，生产构建移除接口。没有模型、远程字体或音频下载。

开发与验收记录见 [Issue #3](https://github.com/lam-guo/zoombie/issues/3) 与 [Issue #5](https://github.com/lam-guo/zoombie/issues/5)。
