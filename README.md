# 最后防线 · LAST LINE

Three.js 浏览器 3D 僵尸射击游戏。固定阵地、四类僵尸、三把可切换武器与弹匣装填，连续挑战五道防线。每关约1–3分钟，清除定额敌人后进入下一关。

## 本地运行

需要 Node.js 22.12+ 和支持 WebGL 2 的现代浏览器。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。首次点击“进入战斗”启用音效。

## 操作

| 操作                     | 效果                           |
| ------------------------ | ------------------------------ |
| 移动鼠标 / 手指拖动      | 瞄准                           |
| 按住左键 / 长按场地      | 持续开火                       |
| 1 / 2 / 3 或底部武器按钮 | 切换步枪、狙击、霰弹；释放开火 |
| R 或装填按钮             | 手动装填，空仓也会自动装填     |
| Esc / P                  | 暂停或继续                     |
| 失败时 R / 重试本关      | 重新挑战当前关                 |
| 右上角声音按钮           | 静音或恢复声音                 |

步枪30发，狙击5发且最多穿透三只，霰弹6发且为近距范围攻击。各枪弹匣独立、备弹不限。切枪取消未完成的装填；暂停则冻结装填。

每关补满生命和三把枪的弹匣，失败重试当前关；五关完成后可以重新出击。失焦与切换浏览器标签自动暂停，返回后手动继续。无账号、存档或后端。

详细数值、五关配额、通关规则和计时边界见 [玩法文档](docs/gameplay.md)。首版以电脑验收，已提供响应布局、触摸按钮；手机性能仍需真机专项验证。

## 验证与构建

```sh
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:campaign
npm run test:soak
npm run preview
```

产物在 `dist/`，可由静态 HTTP 服务提供。GitHub Actions 在 PR 上执行单元测试、类型检查/构建和常规浏览器交互测试，不自动部署。

`test:campaign` 使用真实浏览器输入完成五关、验证最终胜利和重开；通过浏览器时钟缩短等待，不修改游戏状态。`test:soak` 执行五分钟实际墙钟运行并检查活体、尸体、特效和浏览器错误。这些软件渲染测试输出环境与FPS，不能作为硬件性能承诺。

## 实现

- `src/game/types.ts`：共享状态、四类敌人、三枪与五关数值。
- `src/game/simulation.ts`：不依赖渲染的战斗、装填、定额出怪与关卡状态机。
- `src/game/world.ts`：程序化场景、角色/武器模型、动画与特效池。
- `src/game/audio.ts`：Web Audio 合成音效。
- `src/main.ts`：输入、页面生命周期、对局界面与主循环。

开发服务器显式使用 `/?inspect` 时提供只读 `window.__game.snapshot()` 和 `project()`，生产构建移除接口。没有模型、远程字体或音频下载。

开发与验收记录见 [Issue #3](https://github.com/lam-guo/zoombie/issues/3)。
